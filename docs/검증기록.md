**32개 시나리오 중 32개 통과.** 20개 게임 모두 성공 결과까지 진행했습니다. 최종 종단 실행과 예외 경로 실행에서 수집한 JavaScript 페이지 오류·콘솔 오류는 0건이었습니다. 단일 HTML의 종단 테스트에서는 외부 네트워크 요청이 없었습니다.

## 방법과 환경

- Linux의 Chromium 144.0.7559.96, Python Playwright를 사용했습니다.
- 이 실행 환경은 파일 URL과 로컬 HTTP 페이지의 브라우저 이동을 제한하여, 동일한 단일 HTML 바이트를 `page.set_content()`로 로드했습니다. 소스 구조·단일 HTML의 자원 포함 여부는 별도로 점검했습니다. Windows 탐색기에서 더블클릭해 여는 동작 자체는 이 환경에서 확인하지 못했습니다.
- 데스크톱 1440×1040, 모바일 레이아웃 390×844를 확인했습니다. 터치 검증은 기기 배율 2와 터치 입력을 지원하도록 설정한 Chromium 에뮬레이션에서 수행했습니다. 실제 iPhone·Android 하드웨어 검증은 아닙니다.
- 퍼즐 검증에서는 테스트 코드가 내부 상태·기하 정보를 읽어 입력을 준비했습니다. 플레이 상태를 성공 상태로 강제로 바꾸거나 게임 시간을 건너뛰지 않고, 마우스·키보드·range input 이벤트로 규칙과 화면의 연결을 확인했습니다. 소나 위치는 탐침 거리 3개로 계산했습니다.
- 브라우저 오디오 엔진의 running 상태, 스텝 재생, 패턴 일치와 소스 정지는 확인했습니다. 실제 스피커의 청감·음질은 이 테스트의 검증 범위가 아닙니다.

## 수명·레이아웃

일시정지 중 경과 시간 정지, 재개 후 시간 진행, 이전 세션의 alive=false·AbortSignal 해제·후속 예약 큐 0, 이전 오디오 소스 0을 확인했습니다. 20회 추가 게임 전환 후에도 오류가 없었습니다. 일시정지/재개가 카드의 연속 사용 제한을 지우지 않는지 별도로 확인했습니다.

20개 게임의 데스크톱 및 390px 모바일 화면에서 가로 넘침이 없었습니다. 터치로 주사위를 당겨 던지고, 별자리 게임을 완료하고, 작은 결과창에서 재시작 버튼까지 눌렀습니다. 짧은 화면에서는 결과 카드 안쪽을 스크롤해 버튼을 사용할 수 있습니다.
