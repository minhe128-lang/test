# OVERKILL · 쓸데없이 거대한 오락실

원본 `test-main.zip`의 20개 테마와 장면 이미지를 바탕으로, 각 장치를 직접 플레이하는 오프라인 미니게임 모음으로 다시 구성했습니다.

## 실행

**가장 간단한 실행:** `OVERKILL_바로실행.html`을 저장한 뒤 브라우저로 여세요. 이미지, 스타일, 스크립트가 이 파일 안에 모두 들어 있습니다.

**수정용 소스 실행:** ZIP 전체를 압축 해제한 뒤 `index.html`을 여세요. `assets` 폴더를 같은 위치에 두어야 합니다. 서버, 계정, API 키, 빌드 도구는 플레이에 필요하지 않습니다.

소리는 처음에 꺼져 있습니다. 상단의 `소리 OFF`를 누르면 켜집니다. 음악 콘솔의 재생·예시 듣기는 사용자의 명시적 재생 요청으로 소리를 켭니다. 브라우저의 자동 재생 제한 때문에 파일을 열자마자 소리가 나지는 않습니다.

## 이번 버전의 구조

20개에 같은 실행 버튼과 자동 연출을 붙이지 않았습니다. 물리 투척, 버튼 추격, 바람 그리기, 실제 시간 되감기, 압력 균형, 시퀀서, 관성 비행, 상대 수 읽기, 거리 추론, 체감 시간, 카드 전술, 노노그램, 숫자 미로, 암호 추리, 문장 판결, 재료 배합, 별자리 연결, 문자 수색, 파형 조율, 환산 경로를 각각 구현했습니다.

점수는 명중, 실수, 정확도, 남은 자원, 실제 퍼즐 해결 결과에서 계산합니다. 실행 버튼을 누른 횟수만으로 성공 점수를 지급하지 않습니다. 각 게임의 최고점·획득한 별·방문 기록은 해당 브라우저의 로컬 저장소에만 남깁니다. 저장이 금지된 환경에서도 플레이는 가능하지만 파일을 다시 열면 기록이 유지되지 않을 수 있습니다.

`Esc`는 일시정지/재개입니다. 결과 화면에서는 실험 목록으로 돌아갑니다. 현재 실험의 `다시 시작`은 해당 실험만 초기화합니다. 다른 게임으로 이동하면 이전 게임의 입력, 예약된 후속 동작, 렌더링 루프와 소리가 종료됩니다.

`FULL / LITE`는 장식 효과와 캔버스 해상도 부담을 조절합니다. LITE에서도 게임 규칙, 판정과 핵심 조작은 동일합니다.

## 실제로 사용할 수 있는 부가 기능

- **이미지 압축:** 프레스의 `실제 이미지 압축`을 펼치세요. 기본 샘플 또는 선택한 이미지를 브라우저에서 JPEG로 변환하고 파일을 저장합니다. 품질 조절, 실제 바이트 수 비교, 최대 변 길이 4096px 처리를 지원합니다. 파일은 서버로 전송하지 않습니다. 투명 영역은 흰색이 되며 GIF는 정지 이미지로 처리합니다. 이미 압축된 파일은 결과가 더 커질 수 있고, 이 경우 증가했다고 표시합니다.
- **문서 조사:** 문서 심문실에서 직접 입력한 텍스트의 글자 수, 공백 제외 수, UTF-8 바이트, 공백 기준 어절을 계산합니다. `Intl.Segmenter` 지원 환경에서는 결합 문자와 가족 이모지 같은 묶음도 사용자가 보는 문자 단위로 셉니다.
- **비밀번호:** 금고 성공 후 `crypto.getRandomValues`를 이용해 24자리 문자열을 별도로 생성합니다. 게임의 A–F 정답을 비밀번호로 재사용하지 않으며 생성 문자열은 게임 기록에 저장하지 않습니다. 보안 난수 기능이 없으면 생성하지 않습니다.
- **비행 기록:** 비행 종료 후 버튼을 누르면 실제 `.txt` 기록을 저장합니다. 비행을 시작하거나 덮개를 여는 동작만으로 파일이 자동 저장되지는 않습니다.
- **음악 콘솔:** 킥, 스네어, 하이햇, 베이스가 실제로 합성됩니다. 외부 음원이나 노래를 사용하지 않습니다.

## 원본 기능과 달라진 점

이번 결과물은 실용 도구 모음이 아니라 **플레이를 우선한 게임 모음**입니다. 날씨는 실시간 예보가 아니라 도시 방어 게임이고, 환율은 실제 시세가 아니라 가상의 수학 퍼즐입니다. QR 제조소는 노노그램으로, 결과가 스캔 가능한 QR 코드는 아닙니다. 맞춤법은 고정 문제이며 임의의 문장을 교정하는 서비스가 아닙니다. 궁합은 관계나 성격을 평가하지 않고 실제 파형의 좌표 오차를 계산합니다.

이 구분은 각 게임의 화면에도 표시했습니다. 기능이 없는데 있는 것처럼 성공 연출만 재생하지 않습니다.

## 파일 구성

```text
index.html                     수정용 페이지 진입점
OVERKILL_바로실행.html           모든 자원이 포함된 단일 실행 파일
assets/arcade.css               반응형 화면·컴포넌트 스타일
assets/js/core.js               세션, 입력 수명, 오디오, 점수, 그리기 기반
assets/js/games-physics.js      물리·시간·압력 게임
assets/js/games-mind.js         추론·문자·숫자·전술 게임
assets/js/games-lab.js          음악·배합·별자리·파형 게임
assets/js/main.js               목록, 분류, 검색, 화면 이동
assets/scenes/                 원본 ZIP의 장면 이미지
tools/build_standalone.py       단일 HTML 재생성 도구
tools/test_arcade.py            브라우저 종단 검증 스크립트
docs/                         검증 결과와 구현 메모
```

소스를 수정한 뒤 단일 HTML도 갱신하려면 프로젝트 폴더에서 다음을 실행하세요.

```sh
python tools/build_standalone.py
```

이 명령은 Python 표준 라이브러리만 사용합니다. 자동 브라우저 검증은 별도로 Python Playwright와 Chromium 실행 환경이 필요합니다. 실제 플레이에는 Python이 필요하지 않습니다.

## 검증 범위

`docs/검증기록.md`에 테스트 환경, 실제로 실행한 성공·실패 경로, 제한 사항을 기록했습니다. 자동 검증은 조작 연결과 규칙·수명 관리의 확인이지, 모든 사람의 재미나 모든 기기의 성능을 보증하는 수단은 아닙니다.

원본은 수정하지 않았습니다. 장면 이미지는 사용자가 제공한 원본 ZIP의 자산을 재사용했고, 별도의 폰트 파일이나 외부 CDN은 포함하지 않았습니다.
