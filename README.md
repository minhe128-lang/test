# 쓸데없이 거대한 도구함 20선

HTML, CSS, JavaScript로 만든 정적 웹사이트입니다. 20개 도구가 실제로 작동하며, 각 기능마다 별도의 화면 구성과 실행 연출이 들어 있습니다.

## 실행

폴더 구조를 유지한 채 `index.html`을 열면 됩니다. 브라우저 보안 때문에 일부 API가 막히면 아래처럼 로컬 서버로 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## Render 배포

- 서비스 종류: Static Site
- 빌드 명령: 비워두기
- 배포 폴더: `.`

## 외부 연결 기능

- 서울 날씨: Open-Meteo
- 환율: Frankfurter
- QR 생성: qrcode.js

그 밖의 타이머, 난수, 문서 분석, 맞춤법 판정, 이미지 압축, 다운로드 등은 브라우저에서 직접 처리합니다.
